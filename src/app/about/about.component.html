Sobre el proyecto

Este proyecto es un sistema de inventarios Full Stack que permite visualizar, crear, editar y eliminar productos. Fue desarrollado con fines de portafolio, enfocado en aplicar buenas prácticas de desarrollo de Front End como Back End.

El sistema permite llevar un control básico de productos simulando un flujo en aplicaciones administrativas reales.

Tecnologías utilizadas:

  • JAVA 21 con Spring Boot 4
  • Spring Data JPA + Hibernate
  • MySQL
  • Angular 19 (Standalone)
  • RxJS (Manejo reactivo de estado)
  • REST API

Buenas Prácticas utilizadas:

  • Arquitectura por capas (Controller, Service, Repository)
  • Uso de DTOs y validaciones con Bean Validation
  • Manejo de estado reactivo en Angular con Observables (BehaviorSubject)
  • Separación de responsabilidades entre componentes y servicios
  • Validaciones tanto en Front End como en Back End
  • Manejo de CORS y comunicación REST
